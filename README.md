# نور | NOOR — المنصة الإسلامية المتكاملة لجمهورية مصر العربية 🕌

منصة ويب إسلامية عربية متكاملة وعالية الأداء مبنية باستخدام **Next.js 15 (App Router)** و **React 19** و **TypeScript** و **Tailwind CSS**، ومصممة خصيصًا لجمهورية مصر العربية بدعم كامل للغة العربية واتجاه **RTL** والوضعين النهاري والليلي.

---

## أبرز المميزات والأقسام

### 1. لوحة التحكم الرئيسية (Dashboard)
- **بطاقة مواقيت الصلاة الرئيسية**: تعرض المحافظة والمدينة الحالية، التاريخ الهجري والميلادي، الصلاة المفروضة القادمة مع عدّ تنازلي حيّ بالثواني (`HH:MM:SS`)، شريط التقدم الزمني، ومواقيت الصلوات الخمس مع تمييز وقت الشروق وأوقات السنة الليلية (منتصف الليل والثلث الأخير).
- **بطاقة القبلة المصغرة**: تعرض زاوية القبلة بالدرجات من الشمال الحقيقي، الاتجاه الجغرافي، المسافة الجوية إلى الكعبة المشرفة، وبوصلة مرئية.
- **بطاقة ورد القرآن اليومي**: متابعة سريعة للهدف اليومي، نسبة الإنجاز، زر إتمام الورد، والانتقال المباشر لآخر موضع قراءة محفوظ.
- **محتوى إيماني يومي موثق**: آية قرآنية يومية مع وقفة تدبرية، حديث نبوي شريف موثق من الصحيحين مع الراوي ودرجة الصحة، ذكر يومي، ودعاء يومي مع إمكانية النسخ والمشاركة.

### 2. مواقيت الصلاة في جميع محافظات مصر الـ 27 (`/prayer-times`)
- دعم كامل لجميع محافظات مصر الـ **27** (القاهرة، الجيزة، الإسكندرية، الدقهلية، دمياط، الشرقية، الغربية، المنوفية، القليوبية، كفر الشيخ، البحيرة، الإسماعيلية، السويس، بورسعيد، شمال سيناء، جنوب سيناء، البحر الأحمر، الفيوم، بني سويف، المنيا، أسيوط، سوهاج، قنا، الأقصر، أسوان، الوادي الجديد، مطروح) مع أكثر من **180 مدينة ومركز** بإحداثيات جغرافية مستقلة لكل مدينة.
- حساب فلكي دقيق عبر مكتبة `adhan` وفق **الهيئة المصرية العامة للمساحة** افتراضيًا (زاوية الفجر `19.5°`، زاوية العشاء `17.5°`، ومذهب الجمهور للعصر)، مع إتاحة 7 طرق حساب عالمية أخرى، والاختيار بين مذهب الجمهور والمذهب الحنفي، وإضافة فروق دقائق يدوية لكل صلاة.
- عرض مواقيت **اليوم**، **الأسبوع (7 أيام)**، و**جدول الشهر الكامل (الإمساكية)** مع إمكانية الطباعة.

### 3. اتجاه القبلة والبوصلة التفاعلية وأقرب المساجد (`/qibla`)
- حساب زاوية القبلة الدقيقة بالدرجات من الشمال الحقيقي والمسافة بالكيلومتر إلى الكعبة المشرفة بمكة المكرمة (`21.4225° N, 39.8262° E`).
- دعم مستشعرات البوصلة في الهواتف (`DeviceOrientationEvent`) مع تنبيهات معايرة البوصلة بحركة رقم `(8)`، ووضع بديل يعتمد على الاتجاه الجغرافي المحسوب عند عدم توفر الحساسات.
- قسم **أقرب المساجد** مع خريطة تفاعلية (`OpenStreetMap`) وروابط مباشرة للبحث عن المساجد القريبة في خرائط Google.

### 4. القرآن الكريم كاملًا بالرسم العثماني وورد القراءة (`/quran` و `/quran/[surah]`)
- جميع سور القرآن الكريم الـ **114** (**6,236 آية**) مضمنة محليًا بالرسم العثماني الكامل مع التشكيل وعلامات الوقف (تعمل حتى في حالة انقطاع الإنترنت).
- **وضعان للقراءة**: وضع المصحف المتصل ووضع البطاقات (آية بآية)، مع التحكم في حجم الخط القرآني (4 مستويات).
- **البحث الفوري في القرآن الكريم** (`/api/quran/search`): بحث نصي سريع غير حساس للتشكيل والهمزات في جميع آيات المصحف.
- **مشغل التلاوات الصوتية**: الاستماع لكبار قراء مصر والعالم الإسلامي (الشيخ محمود خليل الحصري، الشيخ محمد صديق المنشاوي، الشيخ عبد الباسط عبد الصمد، الشيخ مشاري العفاسي، الشيخ ماهر المعيقلي) مع التحكم في السرعة والصوت والتنقل التلقائي بين الآيات.
- حفظ **آخر موضع قراءة**، **العلامات المرجعية (Bookmarks)**، وتخزين السور المقروءة في `IndexedDB`.
- **نظام الورد اليومي والأسبوعي**: تحديد الهدف بالصفحات أو الآيات أو الأجزاء، مؤشر الإنجاز اليومي والأسبوعي، وسجل المتابعة.

### 5. أذكار المسلم والأدعية الموثقة (`/adhkar`، `/adhkar/morning`، `/adhkar/evening`)
- 7 تصنيفات موثقة من كتاب **حصن المسلم**: أذكار الصباح، أذكار المساء، أذكار بعد الصلاة المفروضة، أذكار النوم، أذكار الاستيقاظ، أذكار متنوعة، والأدعية النبوية والقرآنية، بالإضافة إلى قائمة المفضلة.
- عداد تفاعلي لكل ذكر مع اهتزاز خفيف، وضع القراءة المتتابعة أو القائمة الكاملة، وحفظ التقدم اليومي مع إعادة الضبط التلقائية كل يوم جديد.

### 6. المسبحة الإلكترونية (`/tasbeeh`)
- تصميم مريح للاستخدام بيد واحدة مع حلقة تقدم بصرية، دعم الاهتزاز، طلب تأكيد قبل التصفير، قائمة بالأذكار المأثورة، إمكانية إضافة ذكر مخصص، وإحصائيات يومية وتراكمية.

### 7. التقويم الهجري وأسماء الله الحسنى وحاسبة الزكاة (`/calendar`)
- تقويم شهري مزدوج (هجري / ميلادي) مع قائمة المناسبات الإسلامية السنوية وتنبيه الرؤية الشرعية لدار الإفتاء المصرية.
- **أسماء الله الحسنى الـ 99** كاملة بالتشكيل ومعانيها الموثقة مع البحث الفوري.
- **حاسبة الزكاة التقديرية** (النقد، الذهب عيار 24/21/18، عروض التجارة، وخصم الديون) مقارنةً بنصاب الذهب (85 جرامًا عيار 24).
- **سجل الإنجاز الإيماني** المحفوظ في `IndexedDB`.

### 8. نظام تنبيهات الصلاة والإعدادات والخصوصية (`/settings`)
- إعدادات تنبيه مستقلة لكل صلاة، تنبيه قبل الأذان، وتذكير بموعد الإقامة.
- نغمات تنبيه صوتية مولدة قانونيًا عبر `Web Audio API` دون ملفات خارجية ثقيلة، مع دعم إشعارات المتصفح (`Notification API`) وتوضيح شفاف لقيود المتصفحات في الخلفية.
- إدارة كاملة للبيانات المحلية: تصدير نسخة احتياطية (`JSON`) أو حذف جميع البيانات المحلية من `LocalStorage` و `IndexedDB`.

## طريقة تشغيل المشروع محليًا

### 1. المتطلبات الأساسية
- **Node.js** بإصدار `18.18+` أو `20+` أو `22+`.
- مدير الحزم `npm`.

### 2. تثبيت الحزم
```bash
npm install
```

### 3. إعداد متغيرات البيئة (اختياري)
المشروع يعمل بالكامل دون الحاجة لأي مفاتيح API سرية. يمكنك نسخ ملف `.env.example` إلى `.env.local` عند الرغبة في تخصيص رابط الموقع:
```bash
cp .env.example .env.local
```

### 4. تشغيل خادم التطوير
```bash
npm run dev
```
ثم افتح المتصفح على العنوان: `http://localhost:3000`

### 5. تشغيل الاختبارات وفحص الأنواع والبناء للإنتاج
```bash
# تشغيل اختبارات الحسابات الفلكية والقبلة والقرآن
npm test

# فحص أنواع TypeScript
npm run typecheck

# بناء نسخة الإنتاج المحسنة
npm run build
npm run start
```

## توثيق المصادر الشرعية والتقنية

1. **مواقيت الصلاة واتجاه القبلة**:
   - مكتبة [`adhan`](https://www.npmjs.com/package/adhan) الفلكية المبنية على خوارزميات *Jean Meeus*.
   - المعيار الافتراضي: **الهيئة المصرية العامة للمساحة** (`Egyptian General Authority of Survey` — زاوية الفجر `19.5°`، زاوية العشاء `17.5°`).
2. **القرآن الكريم والتلاوات الصوتية**:
   - النص القرآني: الرسم العثماني الموافق لمصحف المدينة النبوية (`quran-json` / `Tanzil`).
   - التلاوات الصوتية: شبكة [`EveryAyah`](https://everyayah.com/) الموثوقة لتلاوات كبار القراء.
3. **الأذكار والأحاديث النبوية**:
   - الأذكار: كتاب *«حصن المسلم من أذكار الكتاب والسنة»* للشيخ د. سعيد بن علي بن وهف القحطاني.
   - الأحاديث: مخرجة من *صحيح البخاري* و*صحيح مسلم* مع ذكر الراوي ورقم الحديث ودرجة الصحة.
